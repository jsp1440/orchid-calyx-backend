HARDEN THE CALYX BACKEND FOR SECURITY & APP STORE COMPLIANCE

Project: FastAPI + SQLAlchemy backend for Calyx Orchid Show Management System.

DO NOT rebuild the project.
DO NOT regenerate the schema.
ONLY add security hardening, privacy compliance, and safe configuration.

--------------------------------------------------
1. ADD SECURITY MIDDLEWARE
--------------------------------------------------

Implement:

• HTTPS redirect enforcement (if behind proxy respect X-Forwarded-Proto)
• CORS configuration (restrict to allowed frontend origins via ENV variable FRONTEND_ORIGINS)
• Rate limiting (100 requests per minute per IP) using slowapi
• Request size limit for uploads (max 10MB)
• Security headers middleware:
  - X-Content-Type-Options: nosniff
  - X-Frame-Options: DENY
  - Referrer-Policy: strict-origin-when-cross-origin
  - Content-Security-Policy basic default-src 'self'

--------------------------------------------------
2. ENVIRONMENT VARIABLE VALIDATION
--------------------------------------------------

On startup:

• Validate required ENV vars:
  DATABASE_URL
  STRIPE_SECRET_KEY
  STRIPE_WEBHOOK_SECRET
  FRONTEND_ORIGINS

If missing, raise startup error.

--------------------------------------------------
3. STRIPE SECURITY
--------------------------------------------------

• Verify webhook signatures using STRIPE_WEBHOOK_SECRET
• Reject unsigned webhook requests
• Do not log full payment payloads
• Do not store full card data

--------------------------------------------------
4. ROLE-BASED ACCESS CONTROL
--------------------------------------------------

Add simple RBAC:

Roles:
  admin
  judge
  exhibitor
  public

Protect:
  /admin/*
  /judging/*
  /entries/*
  /scores/*

Only allow appropriate roles.

--------------------------------------------------
5. INPUT VALIDATION
--------------------------------------------------

• Ensure all POST/PUT endpoints use Pydantic models
• Sanitize text fields
• Prevent raw SQL execution
• Ensure all DB access uses SQLAlchemy ORM only

--------------------------------------------------
6. IMAGE UPLOAD SAFETY
--------------------------------------------------

• Accept only image MIME types
• Validate file extension
• Do not execute uploaded files
• Store images in defined media directory or object storage
• Generate random filenames

--------------------------------------------------

This:
• Deletes user record

• Deletes associated judging data
• Returns confirmation JSON
