# BUILD-085A semantic index foundation

The additive `oc_semantic_index` layer indexes derived representations and never replaces canonical BUILD-084 evidence. Index documents retain immutable revision/run identity, canonical parent pointers, ordered source anchors, collections, representation type, hashes, policy, verification, language, consumers, and temporal metadata.

Providers implement token counting, validation, batch embedding, dimensions, metadata, and retry classification. CI uses a deterministic local normalized provider; no paid or network provider is required. Eligibility is decided before provider use and operator authentication never overrides data-handling or internal-indexing policy. Unknown rights route to review.

Preview persists NEW/change/reuse/policy/review/tombstone decisions without vectors. Execution uses per-item safe boundaries, dimension validation, lexical preparation, warnings, partial completion, cancellation/resume, and retained version history. Refresh deactivates prior index versions and writes auditable tombstones without deleting BUILD-084 objects.

Protocol chunks, result narratives, treatment sections, key nodes, insights, events, claims, and accessibility text always point to complete canonical parents. Restricted text is neither logged nor returned by indexing endpoints.

“BUILD-085A creates versioned semantic and lexical index records over preserved BUILD-084 evidence objects. It does not yet implement final hybrid retrieval, question answering, knowledge extraction, graph publication, scientific reasoning, experimental design, or conservation recommendations.”

BUILD-085B is deferred for semantic and lexical query execution, hybrid fusion, metadata filters, parent expansion, citation-aware assembly, ranking, diversity/deduplication, temporal/reliability scoring, retrieval APIs, and retrieval evaluation.
