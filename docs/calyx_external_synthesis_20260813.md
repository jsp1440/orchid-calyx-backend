# CALYX-SPEAK-009 — External review synthesis routing

This change fixes the live failure observed with forwarded wet-winter/El Niño orchid questions.

When local canonical retrieval is empty but Europe PMC discovery returns review-required records, Speak no longer launches a canonical Brain mission that is expected to block with zero canonical sources during ordinary `research_mode=auto` conversation. Instead, the generative conversational provider receives the bounded external records directly for a provisional, explicitly review-required synthesis.

The canonical Brain mission remains available under `research_mode=always`. External records remain noncanonical, review-required, non-publishing, and non-mutating.

Wet-winter literature discovery now prioritizes waterlogging, hypoxia, root/crown rot, Phytophthora/Pythium, moisture, and temperature rather than drifting into generic flowering, scent, color, or pollination literature.

Long mission questions preserve both the beginning and end of the current scientific request instead of retaining only the final 1000 characters.
