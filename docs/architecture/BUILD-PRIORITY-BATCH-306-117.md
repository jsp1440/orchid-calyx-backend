# Priority Batch — BUILD-KE-306 through BUILD-BRAIN-117

Status: candidate implementation; draft only.

## Implemented vertical slices

1. **BUILD-KE-306** — deterministic accessible-media selection for integrated glossary cards using relevance, accessibility, evidence, licensing, and alt-text requirements.
2. **BUILD-ATLAS-407** — evidence-linked sampling-gap ranking using suitability, observation counts, and sampling effort; outputs remain candidate survey priorities.
3. **BUILD-RS-504** — provenance notebook manifests linking environment checksums, ordered cells, source checksums, and input/output artifacts; execution remains disabled.
4. **BUILD-CON-604** — idempotent specimen bloom histories with image assets, flower counts, chronology validation, and conflict rejection.
5. **BUILD-MATRIX-704** — confidence-calibration summaries separating predicted confidence from observed accuracy.
6. **BUILD-VISION-804** — candidate herbarium interpretations for labels, taxa, dates, and localities tied to evidence regions.
7. **BUILD-PUB-904** — deterministic grant-package assembly requiring need, objectives, methods, outcomes, budget, and evidence; submission remains disabled.
8. **BUILD-INT-955** — versioned event-schema compatibility checks that identify removed or missing required fields.
9. **BUILD-MC-205** — deterministic critical-path projection with missing-dependency and cycle rejection.
10. **BUILD-BRAIN-117** — candidate duplicate-architecture detection using normalized terms and dependency overlap.

## Validation coverage

Focused tests cover deterministic media selection, sampling-gap ranking, notebook ordering, bloom conflicts, calibration buckets, empty herbarium interpretations, required grant sections, schema incompatibility, critical-path cycles, and duplicate-design candidates.

## Safety boundary

These foundations do not approve survey priorities, execute notebooks, write production collection records, finalize identifications, submit grants, activate schemas, schedule production work, merge architecture objects, deploy services, publish scientific claims, or mutate the production Knowledge Graph.
