## Validation coverage

Focused tests cover unknown concept references, learning-path order, weighted suitability, protocol repeatability, care-event conflicts, Matrix missing data, terminal visual review, deterministic reports, unrouted events, risk filtering, and stable architecture-change IDs.

## Safety boundary

These are bounded candidate contracts. They do not import live scientific datasets, write production specimen records, approve visual claims automatically, publish reports, deliver events externally, merge code, deploy services, or mutate the production Knowledge Graph.
