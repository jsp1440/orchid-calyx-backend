# Priority Batch — BUILD-KE-307 through BUILD-BRAIN-118

Status: candidate implementation; draft only.

## Implemented vertical slices

1. **BUILD-KE-307** — privacy-preserving glossary usage summaries without user identifiers.
2. **BUILD-ATLAS-408** — evidence-linked expedition-site ranking using conservation priority, sampling gaps, and access feasibility.
3. **BUILD-RS-505** — deterministic scientific review packets connecting hypotheses, evidence, artifacts, and required review classes.
4. **BUILD-CON-605** — specimen treatment events with chronology and terminal closure rules.
5. **BUILD-MATRIX-705** — explainable uncertainty grouped into matches, conflicts, missing states, and low-confidence characters.
6. **BUILD-VISION-805** — confidence-ranked candidate orchid-pollinator interaction observations tied to image regions.
7. **BUILD-PUB-905** — deterministic manuscript-section plans with submission disabled.
8. **BUILD-INT-956** — integration contract test cases with payload checksums and expected-validity assertions.
9. **BUILD-MC-206** — agent-capacity summaries by architecture with saturation visibility.
10. **BUILD-BRAIN-118** — governed supersession proposals with rationale, evidence, stable IDs, and no automatic replacement.

## Validation coverage

Focused tests cover aggregate glossary analytics, deterministic expedition ranking, review-packet repeatability, treatment chronology, uncertainty separation, candidate pollinator ordering, manuscript duplicate rejection, integration contract failures, capacity saturation, and supersession safeguards.

## Safety boundary

These contracts do not identify individual learners, authorize expeditions, approve scientific review packets, provide medical or pesticide instructions, finalize taxonomic or pollination claims, submit manuscripts, activate integrations, launch agents, supersede Brain objects automatically, merge code, deploy services, or mutate the production Knowledge Graph.
