Authoritative scientific identity rule: a `reasoning_id` links provenance and reasoning history but is not part of the scientific assertion identity used for Candidate Knowledge deduplication. Independent evidence supporting the same mechanistic assertion therefore strengthens one Candidate Knowledge assertion rather than fragmenting it by reasoning-run identity.

Mechanistic claims remain `MECHANISTIC_RELATIONSHIP` Candidate Knowledge, map to `MECHANISTIC_RELATIONSHIP_AGGREGATE`, and are classified as scientific inference requiring human review. Graph previews use synthetic preview provenance and never claim production Knowledge Graph publication.
