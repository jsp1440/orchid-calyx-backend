# BUILD-BRAIN-114F — Safety boundary

The consolidation branch is a non-production engineering branch. It carries no authority for automatic merge, deployment, publication, taxonomy activation, production database mutation, production Knowledge Graph mutation, credential access, or network-enabled repository execution.

The static validator remains read-only and does not execute repository code. The isolated patch executor remains restricted to explicitly disposable `autonomy/*` workspaces and exact preimage-bound allowlisted paths.
